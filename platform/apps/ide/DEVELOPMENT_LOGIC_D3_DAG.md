# 📈 IDE Client — D3.js Multi-Agent DAG Visualization 

> **Target:** `apps/ide/src/visualization/DagViewer.tsx`
> **Goal:** Render the real-time execution DAG (Directed Acyclic Graph) of the LangGraph AI Orchestrator. Show exactly which agent is running, waiting, or failed.
> **Standard:** Mandated D3.js. High frame-rate. Interactive tooltips. SVG optimization.

## 🧠 Core Engineering Rules for Developer (DO NOT DEVIATE)

### 1. Pure D3 Integration in React (Use Refs)
- **Constraint:** React updates the DOM. D3 also updates the DOM. If both try to mount generic SVG elements like `<circle>` inside the same `<svg>`, React will crash with a "Node not found" error during reconciliations.
- **Elite Logic:**
  - Create an empty container: `<div ref={d3Container} />`.
  - Let React handle the `useEffect` and data fetching.
  - Pass the raw data object to D3. Then, D3 takes 100% control of the `d3Container` DOM mutation.
  - Use `d3.select(d3Container.current)`.

### 2. Enter -> Update -> Exit Pattern
- **Constraint:** If the `ai-service` streams a new DAG state via the `ai:{conversation_id}` WebSocket channel, D3 must not wipe the screen and re-draw everything. It will cause severe visual flashing.
- **Elite Logic:**
  - Map data with exact ID keys: `.data(nodes, d => d.id)`.
  - Handle `.enter()` to smoothly fade in new agents (e.g., `Backend Agent` spawns).
  - Handle `.update()` to change properties if the status moves from `pending` (Gray) -> `running` (Blue pulse) -> `completed` (Green).
  - Use `d3.transition().duration(500)` for the SVG morphing to make it feel extremely premium.

### 3. Infinite Zoom & Pan
- **Constraint:** Complex cloud architectures generated by the agents will result in 15+ nodes. It will not fit in a 300px sidebar pane.
- **Elite Logic:**
  - Implement `d3.zoom()`.
  - Wrap all nodes and edges inside an `<g className="dag-group">`.
  - Apply the zoom transform ONLY to this `<g>` group, not the root SVG.
  - Default the initial load to a `fit-to-screen` algorithm: calculate the outer bounding box of the graph and set `transform = scale(X) translate(Y)`.

### 4. Interactive Data Probes (Tooltips)
- **Constraint:** The user needs to see *why* the QA Agent failed without opening a separate console window.
- **Elite Logic:**
  - Attach `d3.on('mouseover')` to the nodes.
  - On hover, query the localized Zustand state for the specific agent's last JSON output.
  - Position an HTML absolute `div` (Popover Radix UI component) over the SVG coordinates `(event.pageX, event.pageY)`.
  - Do NOT try to render complex multi-line JSON text inside the actual D3 SVG `<g>` elements. Always overlay HTML for layout sanity.
