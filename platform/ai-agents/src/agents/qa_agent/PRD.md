## 1. Executive Summary

The QA (Quality Assurance) Agent generates and runs tests to verify the code generated by Backend, Frontend, and DevOps agents. It provides feedback for the feedback loop in the LangGraph pipeline.

## 5. Implementation

### 5.1 Agent Code (src/agents/qa-agent/agent.py)

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import PydanticOutputParser
from langchain_anthropic import ChatAnthropic
from ..routing.cost_manager import cost_manager
from ..orchestrator.state_schema import QAOutput, AgentState

QA_SYSTEM_PROMPT = """You are a QA Engineer Agent. Your role is to generate and run tests to verify the generated code works correctly.

## Your Responsibilities:
1. Generate unit tests for backend code
2. Generate integration tests for frontend-backend interaction
3. Run tests and capture results
4. Report test coverage
5. Identify and document errors

## Testing Approach:
- Use pytest for Python backend
- Use Vitest for JavaScript/TypeScript frontend
- Focus on critical path tests first
- Test edge cases and error handling

## Output Format:
You must output a valid JSON object with test results and any generated test files.
"""

QA_USER_PROMPT = """## Backend Code:
{backend_code}

## Frontend Code:
{frontend_code}

## Your Task:
1. Analyze the generated code
2. Generate appropriate tests
3. Run the tests (simulated)
4. Report results

Generate tests for:
- API endpoints
- Business logic
- Data validation
- Error handling

Output as JSON with test results.
"""

class QAAgent:
    """QA Engineer Agent - generates and runs tests"""
    
    def __init__(self):
        # Use Tier 2 LLM for test generation
        self.llm = cost_manager.get_llm("tier2")
        self.parser = PydanticOutputParser(pydantic_object=QAOutput)
    
    async def run(self, state: AgentState) -> AgentState:
        """
        Execute the QA Agent
        
        Args:
            state: Current agent state containing code outputs
            
        Returns:
            Updated state with QA output
        """
        # Validate input
        if not state.backend_output and not state.frontend_output:
            state.errors.append("QA Agent: Missing code outputs")
            return state
        
        # Build prompt
        prompt = ChatPromptTemplate.from_messages([
            ("system", QA_SYSTEM_PROMPT),
            ("user", QA_USER_PROMPT)
        ])
        
        # Create chain
        chain = prompt | self.llm.with_structured_output(QAOutput)
        
        # Execute
        try:
            result = await chain.ainvoke({
                "backend_code": state.backend_output.model_dump_json() if state.backend_output else "{}",
                "frontend_code": state.frontend_output.model_dump_json() if state.frontend_output else "{}"
            })
            
            state.qa_output = result
            
        except Exception as e:
            state.errors.append(f"QA Agent error: {str(e)}")
        
        return state
```

## 7. Test Execution

### 7.1 Test Runner

```python
import subprocess
import json

class TestRunner:
    """Execute tests and capture results"""
    
    def run_backend_tests(self, project_id: str) -> dict:
        """Run pytest for backend"""
        result = subprocess.run(
            ["pytest", "-v", "--json-report", "--json-report-file=report.json"],
            capture_output=True,
            text=True
        )
        return self.parse_pytest_output(result)
    
    def run_frontend_tests(self, project_id: str) -> dict:
        """Run Vitest for frontend"""
        result = subprocess.run(
            ["vitest", "run", "--reporter=json"],
            capture_output=True,
            text=True
        )
        return self.parse_vitest_output(result)
    
    def parse_pytest_output(self, result) -> dict:
        """Parse pytest JSON output"""
        try:
            with open("report.json") as f:
                return json.load(f)
        except:
            return {"passed": 0, "failed": 0, "errors": [result.stderr]}
```

## 8. Cost Optimization

### 8.1 Token Usage Tracking

```python
class QACostTracker:
    """Track costs for QA agent"""
    
    # Tier 2 pricing (Claude 3.5 Haiku)
    INPUT_COST_PER_1M = 0.25
    OUTPUT_COST_PER_1M = 1.25
    
    def estimate(self, input_text: str, output_text: str) -> float:
        input_tokens = len(input_text) * 0.75
        output_tokens = len(output_text) * 0.75
        
        return (
            (input_tokens / 1_000_000) * self.INPUT_COST_PER_1M +
            (output_tokens / 1_000_000) * self.OUTPUT_COST_PER_1M
        )
```

### 9.2 Feedback Loop

```python
def should_continue_qa(state: AgentState) -> str:
    """Decide whether to retry or proceed"""
    if state.iteration >= state.max_iterations:
        return "end"  # Max retries reached
    if state.qa_output and state.qa_output.tests_passed:
        return "end"  # Tests passed
    return "retry"  # Tests failed, retry

workflow.add_conditional_edges(
    "qa",
    should_continue_qa,
    {
        "retry": "backend",  # Loop back to fix
        "end": "security"    # Proceed to security
    }
)
```

## 12. Key Implementation Notes

### 12.1 LLM Selection
- **Tier 2**: Test generation (fast/cheap)
- Use Claude 3.5 Haiku or Gemini Flash

### 12.2 Test Coverage
- Unit tests for business logic
- Integration tests for API endpoints
- Edge case coverage

### 12.3 Feedback Loop
- If tests fail, loop back to Backend/Frontend
- Max iterations = 3 to prevent infinite loops
- Track iteration count in state

### 12.4 Cost Control
- Cheaper than Tier 1 agents
- Track usage for billing
